# 内容编辑器使用说明

本说明面向**制作内容的老师**：如何用编辑器做出题目、分支、小游戏和成就，以及如何保存、备份和导出。全程表单操作，**不需要写任何代码或 JSON**。

> 快速回忆：打开框架入口 → "🛠️ 内容编辑器"；第一次建议先"检查与导出 → 📥 载入示例项目"照着改。

---

## 一、界面总览

```
┌──────────────────────────────────────────────────────────┐
│ 顶栏：项目名 | 保存状态 | 💾保存 │ 👀预览 │ 📥导入 │ 📄导出配置 │ 📦导出完整网页 │
├──────────┬───────────────────────────────────────────────┤
│ 左侧树    │ 标签页：🎯关卡与题目 │ 🔀分支流程 │ 📚教学材料 │ 🖼️素材管理 │
│ （阶段    │         🎮小游戏 │ 🏅成就与经验 │ ⚙️API设置 │ ✅检查与导出 │
│  /关卡    │                                               │
│  /题目）   │           中间区域：当前选中对象的表单            │
└──────────┴───────────────────────────────────────────────┘
```

- **左侧树**：点击阶段/关卡/题目即可选中编辑；树顶部有"＋ 阶段 / ＋ 关卡 / ＋ 题目"按钮。
- **自动保存**：任何修改都会在停止操作约 1 秒后自动存入本机浏览器（顶栏显示"已保存"），**刷新、关机都不会丢**；也可以随时点"💾 保存项目"手动保存。
- **👀 预览学生页**：新窗口打开学生页试玩当前内容。

## 二、关卡与题目（🎯 关卡与题目）

### 2.1 新建关卡

左侧树点"＋ 关卡"（或阶段列表里"＋ 在本阶段后添加关卡"），然后在中间填写：

| 字段 | 说明 |
|------|------|
| 关卡名称 | 显示在首页卡片和左侧树 |
| 学习目标 | 进入关卡前展示给学生 |
| 关卡介绍 | 首页卡片上的简介 |
| 关卡开始提示 | 进入关卡时弹出（点击继续关闭） |
| 关卡完成提示 | 过关时弹出 |
| 关卡背景图 | 可选，从已上传素材中选 |
| 入口节点 | 流程起点（一般不用手动改，添加题目/节点时自动维护） |
| 参与成绩统计 | 关掉后本题不计入报告统计 |
| 选做内容 | 首页标注"选做" |
| 彩蛋关卡 | 首页标注"彩蛋"，可配隐藏成就 |
| 完成后进入 | 返回首页 / 进入指定关卡 / 打开学习报告 / 停留在完成页 |

底部"本关题目"列表显示流程中实际出现的题目（按流程顺序），可**编辑 / 复制 / 删除**；下方一排按钮可按题型快速添加题目，新题目会自动接到关卡流程末尾（开始 → 题目 → … → 结束）。

### 2.2 关卡设置里的 8 种题型

点"＋ 单选题 / 多选题 / 判断题 / 填空题 / 开放题 / 排序题 / 配对题 / 图片点选题"添加。所有题型通用的配置：

- **题目文本**、**关联教学材料**（展示原文/参考答案）
- **题目素材**：插入图片/视频/音频（先到"🖼️ 素材管理"上传）
- **提示内容**：学生点"💡 提示"后显示
- **分值**、**参与尝试统计**、**计入报告**、**本题调用 API 评价**（开放题）

各题型特有配置：

| 题型 | 特有配置 |
|------|----------|
| 单选/多选/判断 | 选项列表：文本、✅正确答案（单选一项、多选多项、判断二选一）、**每个选项的专属反馈**、**每个选项的分支去向**、选项素材 |
| 填空 | 多个"可接受答案"（忽略标点/空格/大小写），答对/答错反馈 |
| 开放题 | 参考答案、API 评价开关、通用反馈 |
| 排序 | 条目列表 + 正确顺序 |
| 配对 | 左右项列表，相同"配对键"的算一对 |
| 图片点选 | 上传图片后，在图片上**拖拽画框**设置每个选项的点击区域 |

## 三、分支流程（🔀 分支流程）—— 最重要

### 3.1 什么是流程

每个关卡是一条"节点链"，学生从**入口节点**开始，一个个走下去：

```
[显示文字：欢迎来到…] → [显示问题：咕咚是什么？] → … → [结束本关]
                              │
                       选项B（错误）→ [播放视频：木瓜落水] → [显示问题：视频里发生了什么？] → [返回原题]
```

- 普通节点用"**后续节点**"串起来；
- **问题节点**按选项走：某个选项设置了"分支去向"，学生选它就去分支，没设置就走"后续节点"；
- "**返回原题**"节点会结束当前分支，回到触发它的那道题（例如引导问题答完后回到原题重新选择）。

### 3.2 配置"选B → 播视频 → 引导问题 → 返回原题"（标准四步）

1. **出题**：在"关卡与题目"添加单选题，填好选项 A/B 文本；选项 A 勾选"正确答案"，填两项的反馈。
2. **给选项B配分支**：在选项B那一栏找到"**答这道题后前往**"（分支节点下拉），先留空——我们要新建分支节点。
3. **切到"🔀 分支流程"** 标签页，选中本关：
   - 点"＋播放视频"按钮添加视频节点 → 在节点表单里**选择视频素材**、填标题；
   - 点"＋显示问题"添加引导问题节点 → **关联到引导题目**（引导题目也在"关卡与题目"里先建好）；
   - 点"＋返回原题"添加返回节点（无需更多配置）；
   - 用各节点的"**后续节点**"把它们串起来：视频节点 → 引导问题 → 返回原题。
4. **接通分支**：回到"关卡与题目"选中原题，在选项B的"答这道题后前往"里选择刚才的**视频节点**。
5. 打开"**流程图预览**"确认连线正确；看"**本关分支检查**"是否为"✓ 未发现问题"。

> 分支节点可以复用：多个选项可以指向同一个视频/提示节点。

### 3.3 13 种节点一览

| 节点 | 作用 | 关键配置 |
|------|------|----------|
| 显示文字 | 讲解一段话，学生点继续 | 文字内容、附加素材 |
| 显示问题 | 展示一道题目，按选项分支 | 关联题目 |
| 显示提示 | 展示提示 | 提示内容 |
| 展示原文/高亮 | 展示教材原文，可高亮关键词 | 关联教学材料、高亮词 |
| 显示图片 | 展示一张图 | 图片素材、说明文字 |
| 播放视频 | 学生点击后播放（不自动播放） | 视频素材、允许重播 |
| 播放音频 | 音频播放按钮 | 音频素材 |
| 显示小游戏 | 启动一个已配置的小游戏 | 关联小游戏 |
| 调用API评价 | 评价学生最近的开放题回答 | 是否用全局提示词、自定义提示词、评分标准 |
| 奖励 | 发放经验值/解锁成就 | 经验值数量、关联成就 |
| 跳转 | 跳到指定 节点/关卡/题目/首页/报告/结束 | 跳转目标 |
| 返回原题 | 结束当前分支，回到触发分支的题目 | 无 |
| 结束本关 | 本关流程结束 | 无 |

### 3.4 分支检查（防错）

- 每个关卡有"**本关分支检查**"：死路（节点没有出口）、节点无法退出本关（死循环）会标 ✗；不可达节点标 ⚠。
- 完整检查在"✅ 检查与导出"页，额外覆盖：素材二进制是否还在本机、成就/小游戏引用是否有效、**项目里是否意外含有 API Key**（有则阻止导出）。

## 四、教学材料（📚 教学材料）

课文原文、科普拓展、词语解释、知识点、参考答案/学习建议，分类管理。学生页顶部"课文原文"面板默认展示"教材原文"类材料；题目也可以通过"关联教学材料"引用。支持设置**关键词**用于高亮。

---

## 五、素材管理（🖼️ 素材管理）

- **上传**：把图片/视频/音频拖到上传区（或点击选择文件）。素材存入本机浏览器，**不依赖临时目录**。
- **使用**：题目素材、节点素材、关卡背景图、成就图标、小游戏配图都从下拉里选，**同一个素材可多处复用**。
- **导出**：导出完整网页时，所有被引用的素材会打包成 ZIP 里的 `assets/` 文件，引用路径自动更新，换电脑也不会丢。
- 每个素材卡片显示被引用的次数；删掉的素材如果还被引用，检查页会提醒。

> 建议：图片用 png/jpg，视频用 mp4，音频用 mp3/wav；单个视频尽量控制在 20MB 以内（太大项目配置和导出包都会变大）。

## 六、小游戏（🎮 小游戏）

三个模板，**玩法与教材解耦**——同一套玩法换上任何课文内容都能用：

| 模板 | 玩法 | 可配内容 |
|------|------|----------|
| 🔍 森林线索大搜查 | 在背景图上找热点，全部找到过关 | 背景图、热点位置与名称、需找数量、找到/错过/完成反馈、奖励经验值 |
| 🧩 故事顺序拼拼乐 | 把打乱的卡片排成正确顺序 | 卡片文字/配图（可增删）、正确顺序（↑↓调整）、错误提示、完成反馈、奖励 |
| 🐃 帮野牛当侦探 | 情境选择题，选完看解释 | 开场白、情境描述、行动选项（每个选项的结果与解释）、完成条件、奖励、完成时解锁成就 |

在"关卡与题目"建题时选不了小游戏——小游戏是通过**分支流程里的"显示小游戏"节点**接入关卡的。

## 七、成就与经验值（🏅 成就与经验）

### 7.1 新建成就

"＋ 新建成就"后配置：名称、描述、图标 Emoji（或上传图片）、奖励经验值、是否隐藏、是否可重复，以及**解锁条件**。

### 7.2 条件构建器（12 种）

累计答对题数、首次答对题数、完成关卡数、完成指定小游戏、找到图片线索数、查看原文/提示次数、用提示后答对数、完成开放题数、完成指定彩蛋关、累计经验值，以及两个组合条件：

- **同时满足**：所有子条件都达成（可嵌套）
- **满足其一**：任一子条件达成（可嵌套）

例子："首次答对 3 题" **同时满足** "完成第1关" → 做一个"入门小达人"成就。

### 7.3 经验值规则与防刷取

- 首次答对 / 提示后答对 / 完成小游戏 / 完成开放题 / 查看材料 / 完成关卡 各给多少经验，均可调。
- **防刷新刷取**：每项经验按学习记录里的 `rewarded` 标记只发一次，刷新页面不会重复获得；可重复成就按倍数阈值（如每 5 题）再次触发。

## 八、API 设置（⚙️ API 设置）

用于"AI 点评开放题"。配置入口地址、模型、系统提示词、用户提示词模板（支持 `{question}` `{answer}` `{reference}` `{criteria}` 占位符）、超时时间、失败时的备用反馈。

**API Key 只保存在本机浏览器**（`lls_setting_api_key`），绝不写入项目文件、绝不进入导出包——换电脑/换浏览器需要重新填写。

详细安全须知见 `docs/API配置与安全.md`。

## 九、检查与导出（✅ 检查与导出）

| 按钮 | 作用 |
|------|------|
| 🔍 立即检查 | 错误（✗ 会阻止导出）+ 警告（⚠ 不阻止）全量检查 |
| 📄 导出项目配置（JSON） | 含全部内容与素材（内嵌数据），用于**备份和继续编辑**，可重新导入 |
| 📦 导出完整网页（ZIP） | **交给老师/学生的正式版本**：学生网页 + 引擎 + 素材文件 + 使用说明 + 启动脚本 |
| 📥 载入示例项目 | 载入《咕咚》演示数据（会覆盖当前项目，先备份） |
| 🗑️ 新建空白项目 | 从零开始 |

两种导出的详细区别见 `docs/导入导出说明.md`。

## 十、推荐制作顺序

1. **📚 教学材料**：先把课文原文、拓展资料录进去。
2. **🖼️ 素材管理**：上传本课要用的图片/视频/音频。
3. **🎯 关卡与题目**：建阶段 → 建关卡 → 按顺序加题目（此时已可玩一条直线流程）。
4. **🔀 分支流程**：给需要"答错引导"的选项挂分支（视频/提示/引导问题/返回原题）。
5. **🎮 小游戏**：配置三个模板的内容，再到流程里用"显示小游戏"节点接入。
6. **🏅 成就与经验**：设计里程碑成就（初出茅庐、全部通关、彩蛋猎人…）。
7. **✅ 检查与导出**：立即检查 → 修掉所有 ✗ → 💾 保存 → 📦 导出完整网页。

## 十一、常见问题

**Q：修改后刷新浏览器，内容还在吗？**
A：在。自动保存到本机浏览器；但**清除浏览数据/换浏览器/换电脑**后需要重新导入项目配置 JSON（所以重要项目请定期"📄 导出项目配置"备份）。

**Q：题目/关卡/阶段能调整顺序吗？**
A：阶段和关卡列表里有 ↑↓ 按钮；题目顺序由流程决定（在"分支流程"里调整节点连接）。

**Q：能同时做多个课文项目吗？**
A：编辑器同时只保留一个工作项目。做法：做完课文A → 导出项目配置JSON备份 → 新建空白项目做课文B；之后用"📥 导入项目"切回。每个导出的完整网页是独立的，互不影响。

**Q：学生能跳过关卡/题吗？**
A：流程由你完全控制；把"选做内容"打开的关卡会标为选做，但不影响流程跳转的配置。
