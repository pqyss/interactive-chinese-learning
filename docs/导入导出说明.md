# 导入导出说明

框架提供**两种完全不同的导出**，用途不要搞混：

| | 📄 导出项目配置（JSON） | 📦 导出完整网页（ZIP） |
|---|---|---|
| **给谁用** | **给你自己**（继续修改） | **给老师/学生**（直接运行） |
| 内容 | 全部文字内容 + 素材（转成内嵌数据） | 学生网页 + 引擎 + 素材文件 + 数据 + 说明 + 启动脚本 |
| 能否再导入编辑 | ✅ 可以 | ❌ 不能（那是成品） |
| 能否离线运行 | ❌ 不能 | ✅ 能 |
| 典型场景 | 备份、换电脑、多课文切换 | 交付、发给学生、装到教室电脑 |

---

## 一、导出项目配置（JSON）—— 备份与继续编辑

### 操作

编辑器顶栏 **"📄 导出项目配置"**（或"✅ 检查与导出"页的同一按钮）。

### 导出前自动检查

- 有 ✗ 错误 → **中止导出**并提示修复（防止把坏配置存成备份）；
- ⚠ 警告不阻止，但会在日志里列出。

### 文件内容

一个 `.json` 文件，包含：

- 项目信息、主题色；
- 全部阶段 / 关卡 / 题目 / 分支节点 / 教学材料 / 小游戏 / 成就规则；
- **全部素材**（图片/视频/音频转成 dataURL 内嵌在 JSON 里，单文件自包含）；
- 导出时间戳。

> 注意：**不包含** API Key（本地设置，永不入文件）；**不包含** 学生的学习记录。

### 重新导入

编辑器顶栏 **"📥 导入项目"** → 选择之前导出的 `.json` → 自动完成：

1. 版本检查与迁移（高版本配置文件会被拒绝并提示升级框架）；
2. 素材二进制写回本地库；
3. 项目载入编辑器，关卡/题目/成就/小游戏全部恢复；
4. 文件里的 `api.key` 字段一律丢弃（双保险）。

### 典型用法

| 场景 | 做法 |
|------|------|
| 定期备份 | 每完成一个阶段就导出一次，按日期命名存档 |
| 换电脑/换浏览器 | 旧电脑导出 JSON → 新电脑导入 |
| 做多个课文 | 课文A导出 JSON 备份 → "🗑️ 新建空白项目"做课文B → 随时导入 JSON 切回 |
| 传给同事继续改 | 直接把 JSON 发给对方导入（注意：文件可能较大） |

## 二、导出完整网页（ZIP）—— 交付给学生

### 操作

编辑器顶栏 **"📦 导出完整网页"**（或"✅ 检查与导出"页的主按钮）。

### 导出前自动检查（比配置导出更严）

- 数据校验 ✗ 错误 → 中止；
- **素材二进制存在性**：本地库丢了的素材会阻止导出（避免"视频找不到"）；
- **API Key 泄漏扫描**：项目内容中检测到 `sk-` 长串或 `api.key` 字段 → 阻止导出；
- ⚠ 未使用素材等提示不阻止。

### ZIP 里有什么

```
咕咚互动学习课/
├── index.html              学生入口（双击可运行）
├── data/project.js         全部教学内容（题目/分支/素材清单/成就规则）
├── engine/                 互动引擎（流程/题型/小游戏/成就/报告）
├── shared/                 共享数据模型
├── assets/                 图片、视频、音频素材文件（引用已自动更新）
├── 使用说明.txt
├── 启动学习网页.bat        Windows 一键启动
├── 启动学习网页.command    macOS 一键启动
└── 启动学习网页.sh         Linux 一键启动
```

### 交付给学生/老师

1. 把 ZIP 发给对方；
2. 对方解压后双击"启动学习网页"脚本（或直接双击 `index.html`）；
3. 无需联网、无需安装、无需编辑器；
4. 学生数据只存在对方浏览器本地。

> 详细运行说明见 `docs/学生学习网页说明.md`，可直接把该文档和 ZIP 一起发给老师。

## 三、常见问题与排障

**Q：点导出没反应/提示"无法读取 xxx"？**
A：你可能是直接双击打开的编辑器（file:// 模式），个别浏览器限制读取本地文件。请改用启动脚本（`启动框架.sh/.command/.bat`）以本地服务方式打开编辑器再导出。file:// 模式下框架会自动改用内嵌的引擎源码副本，但素材与项目数据始终可导出。

**Q：导出中止："素材二进制不在本地库中"？**
A：该素材的文件丢失了（例如清理过浏览器数据后项目配置还在）。到"🖼️ 素材管理"找到对应素材**重新上传**即可。

**Q：导出的 JSON 很大（几十 MB）？**
A：正常，素材都内嵌在 JSON 里。建议视频压缩到 20MB 以内；JSON 太大时优先考虑用 ZIP 交付，JSON 仅作备份。

**Q：ZIP 解压后中文文件名乱码？**
A：极少数老旧解压工具不支持 UTF-8 文件名。请使用系统自带解压（Windows 资源管理器 / macOS 归档实用工具）或 7-Zip、WinRAR、Bandizip 等现代工具。框架生成的 ZIP 符合规范（UTF-8 标志位 + CRC 校验），实测 Python/7-Zip/Windows/macOS 均正常。

**Q：能在学生网页上直接改题目吗？**
A：不能，也不建议。请导入项目配置 JSON 到编辑器修改后重新导出，这样内容与素材引用始终一致。

**Q：导入高版本配置文件失败？**
A：配置文件是用更高版本的框架导出的。请升级框架（或让对方用相同版本重新导出）。
