# API 配置与安全说明

本说明面向需要使用"**AI 点评开放题**"功能的老师：怎么配置、Key 存在哪、为什么导出包里没有 Key、以及正式环境下的安全建议。

---

## 一、这个功能是做什么的

学生在开放题（例如"生活中你还听到过哪些有趣的声音？"）写下回答后，可以调用大语言模型给出**鼓励式点评**。不配置 API 时，开放题使用老师预设的"备用反馈"，学习流程完全不受影响。

---

## 二、在编辑器里配置（⚙️ API 设置）

| 字段 | 说明 |
|------|------|
| API 服务地址 | OpenAI 兼容的 chat/completions 地址，如 `https://api.openai.com/v1/chat/completions`（也兼容 DeepSeek、通义、智谱、Moonshot 等 OpenAI 格式的服务） |
| 模型名称 | 如 `gpt-3.5-turbo`、`deepseek-chat`，不填默认 `gpt-3.5-turbo` |
| 请求超时（秒） | 默认 15 秒，超时自动走备用反馈 |
| 系统提示词 | 设定 AI 角色，默认"温柔、耐心的小学语文老师，鼓励式评价" |
| 用户提示词模板 | 支持占位符：`{question}` 题目、`{answer}` 学生回答、`{reference}` 参考答案、`{criteria}` 评价标准 |
| 输出格式要求 | 对输出长度/口吻的额外要求 |
| API 不可用时的备用反馈 | 断网、超时、报错时展示给学生的话 |

**API Key 在哪填**：同一标签页的"本地 API Key"输入框。

### Key 的存储规则（重点）

| 问题 | 答案 |
|------|------|
| 存在哪？ | **只存在制作电脑的浏览器 localStorage**（键名 `lls_setting_api_key`） |
| 会写进项目文件吗？ | **不会**。导入项目时即使文件里带有 `api.key` 字段也会被自动丢弃（双保险） |
| 会进导出包吗？ | **不会**。导出前有专项检查，项目内容中检测到疑似 Key（`sk-` 开头长串）会**阻止导出** |
| 换电脑/换浏览器？ | 需要重新填写一次 |
| 怎么删除？ | 点"清除 Key"按钮，或清除浏览器站点数据 |

## 三、学生端的行为

- **编辑器内预览**（👀 预览学生页）：使用制作电脑的 Key，可以真实体验 AI 点评。
- **导出的完整网页**：默认**不包含 Key**。学生答开放题时，API 调用会失败并自动回退到老师预设的"备用反馈"——不卡死、不报错、不影响继续学习。
- 导出包的文本文件（JS/JSON/HTML/TXT）全部经过泄漏扫描，测试确认无 `sk-` 字样、无 Key 存储键名。

---

## 四、失败回退机制

任何一步出问题都不会打断学习：

```
未配置地址/Key  →  备用反馈
请求超时        →  备用反馈
网络错误        →  备用反馈
HTTP 4xx/5xx    →  备用反馈
返回格式异常    →  备用反馈
```

开放题节点上还有"📖 看参考答案"按钮，学生随时可以查看老师预设的参考答案。

---

## 五、安全须知（请认真阅读）

1. **浏览器直调第三方 API 时，Key 在技术上是可被接触到的**。本框架的默认设计（Key 不入库、不导出、失败回退）已经避免了"把 Key 交给别人"的风险，但如果你在**自己的电脑**上配置了 Key 并让学生试用，请注意：
   - 不要把带有 Key 的浏览器配置文件/项目配置 JSON 发给他人；
   - 导出前养成习惯看一眼"✅ 检查与导出"页的检查结果。
2. **正式环境建议自建代理**：由学校/机构的服务器转发 API 请求，Key 只存放在服务器上，前端不接触 Key。此时把"API 服务地址"填成代理地址即可，本框架无需任何改动。
3. **提示词里不要写学生隐私**：API 请求只包含题目、学生回答等学习内容，但请避免在提示词模板中引导学生提交姓名、电话等个人信息。
4. **费用与限额**：每次开放题提交都会产生一次 API 调用，请注意服务商的额度与速率限制；班级集体使用时建议先用小号测试。

---

## 六、测试连接

API 设置页提供"🔌 测试连接"按钮：用当前配置发一条最小请求，显示是否成功、失败原因（未填地址 / 未填 Key / 超时 / HTTP 状态码 / 格式错误），方便排查。

---

## 七、常见问题

**Q：一定要配 API 吗？**
A：不是。不配就用预设反馈，功能完整可用。API 只是"锦上添花"。

**Q：能用国产大模型吗？**
A：可以。任何 OpenAI 兼容接口（DeepSeek、通义千问、智谱 GLM、Moonshot、Azure OpenAI 兼容端点等）都可以，填对应地址和模型名即可。

**Q：导出的网页里学生能看到 Key 吗？**
A：不能。导出包里根本没有 Key，相关内容经过专项检查。

**Q：Key 填错了会怎样？**
A：API 返回 401，前端自动回退到备用反馈，学生无感知；用"测试连接"可以确认。
