## 已知限制

1. 浏览器直接调用第三方 API 时 Key 可能被技术人员看到，正式环境建议自建代理；框架默认不在导出包中包含 Key。
2. 学习记录保存在学生浏览器的 localStorage 中，更换浏览器或清除浏览数据后会重新统计。
3. 超大视频（数十 MB 以上）会导致项目配置 JSON 和导出包体积过大，建议压缩后使用。
4. 编辑器在 file:// 协议下打开时，导出功能使用内嵌的引擎源码副本；通过启动脚本（http 服务）打开则始终读取最新引擎文件。
