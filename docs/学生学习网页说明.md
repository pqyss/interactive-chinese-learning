# 学生学习网页说明

本说明面向**运行学生网页的老师/家长**。学生网页是老师用框架编辑器导出的一份完整文件夹，**不需要联网、不需要安装任何软件、不依赖编辑器**，拷贝到任何电脑（U 盘/共享盘均可）就能用。

---

## 一、如何打开

导出的是一个 ZIP 压缩包（例如 `咕咚互动学习课.zip`），先**解压**（右键 → 解压到当前文件夹），得到文件夹：

```
咕咚互动学习课/
├── 启动学习网页.bat        ← Windows 双击这个
├── 启动学习网页.command    ← macOS 双击这个
├── 启动学习网页.sh         ← Linux 双击这个
├── index.html             ← 学习入口（也可直接双击）
├── engine/  shared/  data/ assets/   （引擎与内容，勿删）
└── 使用说明.txt
```

| 方式 | 操作 | 说明 |
|------|------|------|
| **推荐** | 双击对应系统的"启动学习网页"脚本 | 自动启动本地服务并打开浏览器；关闭黑色窗口即停止 |
| 直接打开 | 双击 `index.html` | Chrome / Edge / Firefox 均可；个别浏览器安全设置较严时视频可能不播放，此时请用启动脚本 |
| 已知问题 | 启动脚本提示"端口被占用" | 说明 8001 端口被别的程序用了，脚本会自动换个端口，按提示访问即可 |

> 整个文件夹要**一起拷贝**：只拷 `index.html` 会导致题目和素材丢失。

## 二、学生怎么用

打开后是课程首页：一个个关卡卡片（含名称、简介、目标）。点卡片进入关卡。

### 页面布局

```
┌───────────┬───────────────────────────┐
│ 学习进度   │  课文原文（上半部分）        │
│ 经验值     │  ─────────────────────    │
│ 勋章成就墙  │  问题与选项（下半部分）      │
└───────────┴───────────────────────────┘
```

- **左侧**：本关学习进度、累计经验值、已获得的勋章成就（未获得的是剪影）。
- **中上部**：课文原文/科普拓展，学生可随时回看。
- **中下部**：当前问题与选项；部分关卡会穿插小游戏、视频、音频。

### 学习方式

1. 按老师设计的流程前进：读原文 → 答题 → 看反馈。
2. 答错不扣分、不卡死：可能留在原题重答，也可能进入老师设计的**引导分支**（例如看一段视频、回答一个引导问题，然后自动回到原题）。
3. 随时可以点"💡 提示"；提示后答对的经验值会比首次答对少（鼓励先思考）。
4. 完成后弹出过关提示和经验值；达成条件时解锁成就勋章。
5. 右上角"📊 学习报告"随时查看自己的学习情况。

## 三、学习报告

报告页包含：

| 区块 | 内容 |
|------|------|
| 总体学习进度 | 完成关卡数、答对题数、经验值、解锁成就 |
| 答题情况 | 首次答对、提示后答对、做过题数、总作答次数 |
| 知识点掌握 | 按老师设置的知识点标签统计对错 |
| 已解锁成就 | 成就墙 + 解锁时间 |
| 小游戏完成情况 | 各小游戏完成次数 |
| 开放题回答与评价 | 学生写过的回答及 AI/预设评价 |
| 后续复习建议 | 老师预设的复习建议 |

报告页按钮：

- **🖨️ 打印 / 保存为 PDF**：调用浏览器打印，选"另存为 PDF"即可；
- **💾 导出学习记录**：下载 JSON 文件（含每次作答记录），可发给老师存档；
- **🗑️ 清空学习记录**：需确认，清空后重新开始统计；
- **🏠 返回首页**。

## 四、常见问题

**Q：学习记录保存在哪里？会上传吗？**
A：只保存在**本机浏览器的 localStorage**，不联网、不上传。换电脑、换浏览器、或清除浏览数据后，记录会从零开始（这是正常现象，不是故障）。

**Q：家里电脑打不开怎么办？**
A：按顺序尝试：① 用"启动学习网页"脚本打开；② 换个浏览器（推荐 Chrome/Edge）；③ 把整个文件夹拷贝到本地磁盘再打开（不要从压缩包内直接打开、不要放在需要权限的网络位置）。

**Q：视频/图片不显示？**
A：确认 `assets` 文件夹和网页在**同一目录**下一起拷贝了；确认没有被杀毒软件删除文件。

**Q：开放题的"AI 点评"没有反应？**
A：导出网页默认**不包含**老师的 API Key（安全设计）。此时开放题使用老师预设的备用反馈，不影响学习流程。需要 AI 点评时，请老师在编辑器所在电脑上配置 Key 后重新导出。

**Q：想改题目内容？**
A：学生网页不能改内容。请老师用框架的"内容编辑器"导入项目配置 JSON 修改后，重新导出完整网页。不要直接改 `data/project.js`。
