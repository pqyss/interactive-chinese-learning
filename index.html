🧒 儿童互动学习网页制作框架

可视化内容编辑器 + 通用互动学习引擎 + 独立网页导出 · 以小学低年级语文《咕咚》为示例场景

🛠️

内容编辑器

填写题目、选项、分支、素材、小游戏与成就；自动保存在本机浏览器，可导出项目配置或完整网页。
🎒

学生学习网页

运行当前项目（编辑器保存的内容）。给学生的正式版本请通过编辑器“导出完整网页”生成。
📖

使用说明

编辑器功能、分支配置、素材管理、导入导出与 API 配置的完整说明。
推荐使用方式：双击本目录下的 启动框架.sh / .command / .bat 启动本地服务并自动打开入口页面， 也可以手动运行 python3 -m http.server 8000 后访问 http://localhost:8000。 直接双击 HTML 文件通常也能运行；若导出功能异常，请改用启动脚本。 首次使用可在编辑器中“检查与导出 → 载入示例项目”查看《咕咚》演示配置。
