# 儿童互动学习网页制作框架

一个**纯本地运行**的可视化儿童互动学习网页制作工具：用表单做出题目、分支、小游戏和成就，一键导出成**不依赖编辑器、可离线双击运行的完整学习网页**，直接交给老师使用。

示例场景：小学低年级语文《咕咚》+ 声音科普拓展（仅为演示数据，可随时替换成任何课文）。

```
可视化编辑器（做内容）  →  通用互动引擎（跑内容）  →  独立网页导出（交成果）
     不写 JSON                不写死教学内容           ZIP 一键打包
```

## 一、快速开始

### 方式 1：一键启动（推荐）

双击运行对应脚本，会自动启动本地服务并打开入口页面：

| 系统 | 脚本 |
|------|------|
| Windows | `启动框架.bat` |
| macOS | `启动框架.command` |
| Linux / 其他 | `启动框架.sh` |

启动后浏览器访问 **http://localhost:8000**（端口被占用时会提示换端口），入口页面提供三个按钮：

- **🛠️ 内容编辑器** —— 制作和修改学习内容
- **🎒 学生学习网页** —— 试玩当前项目（给学生的正式版请用"导出完整网页"生成）
- **📖 使用说明** —— 完整文档

### 方式 2：手动启动

```bash
cd learning-studio
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 直接双击 `index.html` 通常也能运行；若导出功能异常，请改用上面的启动脚本（导出时需要读取引擎源码文件）。

### 第一次使用

1. 打开编辑器 → 顶部标签 **"✅ 检查与导出"** → 点击 **"📥 载入示例项目"**，即可看到完整的《咕咚》演示配置（6 个关卡 + 彩蛋关）。
2. 在左侧树选择关卡/题目，中间区域修改内容；所有修改**自动保存在本机浏览器**（IndexedDB），刷新不丢失。
3. 点击顶栏 **"▶ 预览"** 立即试玩；点击 **"💾 保存"** 手动保存。
4. 做完后：**"📦 导出完整网页（ZIP）"** 生成可交付给学生/老师的离线网页包。

## 二、项目结构

```
learning-studio/
├── index.html                 入口页面（编辑器 / 学生页 / 文档 三入口）
├── play.html                  学生页（运行当前项目）
├── 启动框架.sh / .command / .bat  一键启动脚本（自动打开浏览器）
│
├── shared/                    【共用层】编辑器与引擎都依赖
│   ├── schema.js              数据模型 / 校验 / 迁移（题目、关卡、节点、成就…）
│   ├── db.js                  IndexedDB 封装（编辑器本地保存）
│   └── zip.js                 纯 JS ZIP 打包器（无第三方依赖）
│
├── editor/                    【内容编辑器】（浏览器内运行，无需安装）
│   ├── editor.html / .css     编辑器界面
│   └── js/
│       ├── app.js             编辑器主程序（左侧树 / 自动保存 / 增删改）
│       ├── panels-core.js     阶段 / 关卡 / 题目 / 材料 面板
│       ├── panels-flow.js     分支流程编辑器（节点 + 流程图 + 检查）
│       ├── panels-misc.js     素材 / 小游戏 / 成就 / API / 检查导出 面板
│       ├── exporter.js        项目配置导出 + 完整网页 ZIP 导出
│       └── embedded-sources.js 引擎源码内嵌副本（file:// 下导出用，自动生成）
│
├── engine/                    【互动学习引擎】（学生页实际执行层）
│   ├── player.css             学生页样式（卡通风格，含打印样式）
│   └── js/
│       ├── store.js           项目加载 / 素材解析 / 学习记录持久化
│       ├── api.js             OpenAI 兼容 API 调用（超时 / 回退）
│       ├── achievements.js    成就判定 + 经验值发放（防刷取）
│       ├── renderers.js       8 种题型渲染与判分
│       ├── games.js           3 个小游戏模板
│       ├── engine.js          流程引擎（13 种节点 / 分支 / 返回原题）
│       └── report.js          学习报告页（打印 / 导出 / 清空）
│
├── examples/
│   └── demo-project.json      《咕咚》示例项目（编辑器内一键载入）
│
├── docs/
│   ├── 使用说明.md            编辑器完整使用说明
│   ├── 学生学习网页说明.md     交给老师/学生的运行说明
│   ├── API配置与安全.md        API 评价功能配置与安全须知
│   ├── 导入导出说明.md         两种导出的区别、用法与排障
│   └── 测试报告.md            56 项端到端实测报告
│
└── tools/
    ├── make-demo.js           示例项目生成器（重新生成 examples/）
    ├── build-embed.js         重新生成引擎内嵌副本（改引擎后运行）
    ├── test-e2e.mjs           端到端测试（Playwright，56 项断言）
    ├── test-image.png         测试用图片
    └── demo-video.webm         测试用视频（示例项目内嵌）
```

**技术要点**：纯 HTML/CSS/JS，零依赖、零构建、零安装；编辑器与引擎共用 `shared/schema.js` 保证数据一致；素材二进制存 IndexedDB，导出时打包进 ZIP。

## 三、功能总览（对照需求）

| 模块 | 能力 |
|------|------|
| 编辑器 | 左侧树 + 8 个标签页；阶段/关卡/题目自由增删、复制、排序；所有内容表单化配置，不写 JSON |
| 题型 | 单选、多选、判断、填空、开放题、图片点选、配对、排序共 8 种；每题可配素材、提示、参考答案、分值、统计开关、是否调 API |
| 分支流程 | 13 种节点（文字/问题/提示/原文高亮/图片/视频/音频/小游戏/API评价/奖励/跳转/返回原题/结束）；**每个选项可配不同分支**（选B→播视频→引导问题→返回原题）；提供流程图预览与死路/不可达/无法退出/素材丢失检查 |
| 素材管理 | 图片/视频/音频上传、复用、删除；导出时自动打包为 `assets/` 文件并更新引用 |
| 小游戏 | 森林线索大搜查（热点）、故事顺序拼拼乐（排序）、帮野牛当侦探（情境选择），玩法与教材解耦、内容全可配 |
| 成就系统 | 12 种条件（含"同时满足/满足其一"组合）、可重复成就、隐藏成就；经验值按记录防刷新刷取 |
| API 评价 | 提示词可编辑；Key 只存本机浏览器，**绝不写入项目文件、绝不进入导出包**；失败自动回退不卡死 |
| 学习记录 | 真实记录（不预填虚构数据）；刷新保留；报告页可打印/存 PDF/导出 JSON/清空 |
| 保存 | 自动保存（IndexedDB）+ 手动保存按钮；支持"导出项目配置 JSON"（含素材，可再导入继续编辑） |
| 导出 | "导出完整网页 ZIP"：学生网页 + 引擎 + 素材文件 + 数据 + 使用说明 + 三系统启动脚本；导出前自动检查 |

## 四、端到端测试

`tools/test-e2e.mjs` 用 Playwright 驱动真实浏览器完成了 **56 项断言**，覆盖：编辑器制作 → 刷新持久 → 配置导出再导入 → ZIP 导出 → 独立目录独立端口运行学生页 → 实际答题（含选项分支视频引导、返回原题）→ 3 个小游戏 → 成就解锁 → 记录持久化 → 报告页 → 记录导出与清空 → API Key 泄漏扫描。

**结果：56/56 全部通过**（详见 `docs/测试报告.md`，由测试脚本自动生成）。

复现方式（需要 Node 18+ 与 Playwright）：

```bash
node tools/test-e2e.mjs
```

测试过程中发现并修复的真实缺陷（均已回归通过）：成就面板 Promise 未 await、DOM 元素被字符串化导致按钮丢失、加题时流程入口被替换、ZIP 中文文件名兼容性、分支反馈展示时间过短等。

## 六、常见问题

**Q：导出的网页到别的电脑上能运行吗？**
A：能。ZIP 解压后双击"启动学习网页.bat/.command/.sh"即可，无需联网、无需安装任何东西。详见 `docs/学生学习网页说明.md`。

**Q：学生的学习记录会上传吗？**
A：不会。记录只存在学生自己浏览器的 localStorage 里，可随时在报告页导出或清空。

**Q：API Key 会被打包进导出文件吗？**
A：不会。Key 只保存在制作电脑的浏览器里；导出前有专项检查，项目文件中出现 Key 会被阻止导出。详见 `docs/API配置与安全.md`。

**Q：修改了引擎代码后要注意什么？**
A：运行 `node tools/build-embed.js` 重新生成内嵌副本，保证 file:// 模式下导出的也是最新引擎。

**Q：示例项目可以删吗？**
A：可以。编辑器里"🗑️ 新建空白项目"即可从零开始；`examples/demo-project.json` 只是演示数据。
